# Themes, colors & grids

## Themes

Boards are `'light'` or `'dark'`:

```js
editor.setTheme('dark')
editor.theme.id            // current theme
editor.on('theme', sync)   // the board menu can switch it too
```

In React, `theme` is a live prop and `onThemeChange` reports in-board
switches back, so the board can follow your app's theme — or drive it:

```jsx
const [theme, setTheme] = useState('light')
<Quickdraw theme={theme} onThemeChange={setTheme} />
```

The board's container also carries `data-qd-theme="light" | "dark"`, which
is handy for styling chrome around the canvas.

## Colors

Shapes store a color *name*, not a hex value. The twelve names —
`black`, `grey`, `light-violet`, `violet`, `blue`, `light-blue`, `yellow`,
`orange`, `green`, `light-green`, `light-red`, `red` — resolve to different
actual colors per theme, so a drawing made on paper still reads on a dark
board.

```js
editor.setStyle('color', 'violet')
```

Highlighter colors get the same treatment with translucency on light boards
and a glow on dark ones.

## Fonts

Text comes in four families — hand-drawn, sans, serif and mono — picked in
the styles panel or with `editor.setStyle('font', …)`. The stacks lead
with the faces tldraw uses, self-hosted in the core package under the SIL
Open Font License: Shantell Sans for hand-drawn text, IBM Plex Sans, Serif
and Mono for the rest. Import the stylesheet next to `quickdraw.css` and
they load on demand, per family and style:

```js
import '@quickdrawjs/core/quickdraw.css'
import '@quickdrawjs/core/fonts.css'
```

Without it the board uses the nearest system faces (Comic Sans or
Chalkboard for hand-drawn text, the platform's sans, serif and mono).
Text re-lays out as the web fonts arrive, so nothing needs to wait for
them. The React Native bundle stays on system faces.

## Grids

Six backdrops: bare paper, grid lines, ruled notebook lines, dotted intersections, blueprint crosses, or an isometric weave.

```js
editor.setGrid('dots')     // 'none' | 'lines' | 'ruled' | 'dots' | 'crosses' | 'iso'
editor.on('grid', sync)
```

Grid spacing adapts to the zoom — doubling and halving around a 40&nbsp;px
page step, with majors every fifth line — and fades in rather than popping.
Grids travel into PNG exports that keep the paper background.

## The action bar

The vertical pill of undo, redo, duplicate and delete is for fingers: it
shows only where the primary input is touch, since with a mouse and
keyboard every one of those is a shortcut away. `actions: 'always'` keeps
it on every device, `'never'` drops it, and `ui.setOptions({ actions })`
flips it live (the `actions` prop in React and React Native).

## The minimap

A small map of the whole drawing sits in the top-right corner: shapes as
blocks, the viewport as a frame. Click or drag on it to put the view there,
scroll on it to zoom, and fold it with the button over its corner. It hides itself on
narrow boards. Hosts that don't want it pass `minimap: false` (the
`minimap` prop in React), or flip it live with `ui.setOptions({ minimap })`.

## The board menu switches

The ⋮ menu includes theme and grid switches by default. If your app owns
its own controls, drop them:

```js
createQuickdraw({ container, themeToggle: false, gridControl: false })
```

```jsx
<Quickdraw themeToggle={false} gridControl={false} />
```
