# Exporting images

## From the toolbar

The board menu exports PNG out of the box: the whole board or the current
selection, on the paper background or transparent, plus copy-as-image to
the clipboard. By default exports download as
`quickdraw-<timestamp>.png`.

## Intercepting exports

Pass `onSave` to receive the blob instead — upload it, attach it, preview
it:

```jsx
<Quickdraw onSave={async (blob, background) => {
  const form = new FormData()
  form.append('file', blob, 'board.png')
  await fetch('/api/upload', { method: 'POST', body: form })
}} />
```

```js
// plain JS
createQuickdraw({ container, onSave: (blob, background) => upload(blob) })
```

## The API

`exportImage` gives you full control from code:

```js
const blob = await editor.exportImage({
  background: true,   // paper background; false = transparent
  scale: 2,           // output pixel density
  margin: 48,         // page-space padding around the content
  ids: null,          // a Set of shape ids to export just those
})
```

Export the current selection:

```js
const blob = await editor.exportImage({
  background: false,
  ids: new Set(editor.selection),
})
```

Exports render the same way the canvas does — grids included when the
paper background is kept — so what you see is what you save.

## SVG

The board menu also exports SVG (the whole board or the selection), and
`onSave` receives it as an `image/svg+xml` blob with `format` set to
`'svg'`. From code:

```js
const svg = editor.exportSvg({
  background: true,   // paper (and grid) behind the drawing
  margin: 48,
  ids: null,          // or a Set of shape ids
})
// a string — save it, inline it, hand it to a design tool
```

Every shape has a vector twin built from the same geometry the canvas
draws with: the pencil's pressure outline, the hand-drawn wobble on
shapes, bent arrows, wrapped text, sticky notes with their shadow, and
images (cropped ones clip their full source). Text uses the board's font
stacks, so the viewer's fonts do the rendering. The isometric grid has no
rectangular tile and is left off the paper.

## React Native

`exportPng` crosses the bridge and resolves with a data URL, ready for
sharing sheets or `FileSystem` writes:

```js
const dataUrl = await board.current.exportPng({ scale: 2 })
```
