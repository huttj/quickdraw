# Headless & custom UI

The stock toolbar is built entirely on the public API — so anything it can
do, your own UI can do. Pass `hideUi` and the canvas renders bare:

```jsx
<Quickdraw ref={ref} hideUi />
```

```js
// plain JS
const board = createQuickdraw({ container, hideUi: true })
```

## Tools

```js
editor.setTool('draw')
// 'select' | 'hand' | 'draw' | 'highlight' | 'eraser' | 'laser'
// | 'arrow' | 'line' | 'geo' | 'text' | 'note'

editor.setGeoKind('star')
// 'rectangle' | 'ellipse' | 'triangle' | 'diamond' | 'hexagon' | 'star'

editor.on('tool', () => highlight(editor.tool))
```

## Styles

```js
editor.setStyle('color', 'blue')   // twelve named colors — see Theming
editor.setStyle('size', 'l')       // 's' | 'm' | 'l' | 'xl'
editor.setStyle('dash', 'dashed')  // 'draw' | 'solid' | 'dashed' | 'dotted'
editor.setStyle('fill', 'semi')    // 'none' | 'semi' | 'solid' | 'pattern'
editor.setStyle('font', 'serif')   // 'draw' | 'sans' | 'serif' | 'mono'
editor.setStyle('align', 'middle') // 'start' | 'middle' | 'end' — text shapes

editor.currentStyles()             // what the next shape will look like
editor.on('styles', refresh)
```

With a selection active, `setStyle` restyles the selected shapes; without
one, it sets the pen for what you draw next — the same behavior the stock
styles panel has.

## Selection

```js
editor.setSelection([id1, id2])
editor.selectAll()
editor.selection                   // a Set of ids
editor.selectionBounds()           // page-space bounds or null
editor.duplicateSelection()
editor.deleteSelection()
editor.on('selection', refresh)
```

## Arranging

```js
editor.bringToFront(); editor.sendToBack()        // all the way
editor.bringForward(); editor.sendBackward()      // one step past a neighbour

editor.alignSelection('left')      // 'left' | 'center' | 'right' | 'top' | 'middle' | 'bottom'
editor.distributeSelection('horizontal')   // or 'vertical' — needs three or more
```

Alignment works on page bounds (rotation included), and a group counts as
one unit, so its members keep their layout.

## Groups

```js
editor.groupSelection()            // ⌘G — needs two or more shapes
editor.ungroupSelection()          // ⇧⌘G
editor.canGroup(); editor.canUngroup()
editor.groupMembers(groupId)       // ids
editor.selectionGroups()           // group ids in the selection
```

A group is a shared `groupId` on its member records — there is no group
record, so persistence and sync consumers see nothing new. Selecting any
member selects the whole group; double-clicking a member focuses the group
(`editor.focusedGroup`) so its members can be picked one at a time, and
`Esc` steps back out. Groups are flat: grouping a selection that contains
groups merges them into one.

## Pasting from tldraw

Copy in tldraw, paste on a Quickdraw board: text, sticky notes, shapes with
their labels, freehand ink and highlights, arrows and lines (with their
bindings), images with their crops, frames, and groups all come across.
tldraw keeps its shapes in the HTML entry of the clipboard, so this works
through the ordinary `⌘V` — which is why `⌘V` is left to the browser's own
paste event instead of the async clipboard API.

```js
import { parseTldrawClipboard } from '@quickdrawjs/core'

const content = parseTldrawClipboard(htmlFromTheClipboard)   // or null
if (content) await editor.importTldraw(content)               // centred in the view, selected
```

Image assets hosted at URLs are fetched into data URLs so they render,
export and sync like Quickdraw's own; one that can't be fetched (a host
without CORS) keeps its URL and still displays. Plain text pasted from
anywhere becomes a text shape.

## Arrow bindings

An arrow (or line) drawn from inside a shape, or ended over one, ties
itself to it: the end lands on the shape's outline and follows the shape
when it moves, resizes or rotates. Drag an end handle onto another shape
to re-tie it, or onto empty paper to free it; hold `⌥` to aim at the exact
point instead of snapping to the shape's centre. Moving a bound arrow on
its own lets go of the shape; moving both together keeps the tie.

```js
arrow.props.startBind   // { id, nx, ny } — the shape and the anchor in its box (0–1)
arrow.props.endBind
editor.bindHover        // while dragging an end: the shape it would tie to
```

The binding is plain data on the arrow's props; the end position is derived
from it by a store reactor (`store.react`) inside the same transaction, so
a moved shape and its arrows are one diff and one undo step.

## Image crop

```js
editor.startCrop(id)               // double-click, Enter, or the context menu
editor.endCrop()                   // keep the crop (Esc, Enter, click away)
editor.resetCrop(id)               // the whole picture again
editor.cropping                    // { id } while in crop mode, else null
editor.on('crop', refresh)
```

In crop mode the whole picture shows faintly around the window, the box
handles trim it, and a drag inside slides the picture behind it. The crop
is stored on the image's props as `crop: { x, y, w, h }` — fractions of the
source, absent for the whole picture — and the whole session undoes as one
step.

## Dropping shapes

```js
editor.dropShape('rectangle', { x, y })   // any geo kind, or 'geo' for the current one
editor.dropShape('arrow', at); editor.dropShape('text', at); editor.dropShape('note', at)
```

This is what a tool dragged off the stock dock does on release: a
ready-made shape centered on the point, in the current styles, selected —
text and notes already open for typing. Returns the new id.

## Context menu

```js
editor.on('contextmenu', ({ x, y, page, hit }) => showMyMenu(x, y))
```

Fires on right-click and on a long press with a finger. By the time it
fires the editor has settled the selection: the shape under the pointer
(with its group) is selected unless it already was, and empty paper clears
the selection. `x`/`y` are screen coordinates inside the container, `page`
is the same point on the board, `hit` the shape record or `null`.

## Camera

```js
editor.fitContent({ animate: 220 })     // zoom to fit
editor.setCamera({ x, y, z })
editor.pan(dx, dy)                      // screen-space delta
editor.zoomAt(sx, sy, 1.2)              // zoom about a screen point
editor.screenToPage(sx, sy)
editor.on('camera', onMove)
```

## History

```js
store.undo(); store.redo()
store.canUndo; store.canRedo
store.listenHistory(refresh)       // fires when can-undo/can-redo change
```

## Showing the stock UI selectively

You don't have to go all-or-nothing. Keep the toolbar but drop the board
menu's theme/grid switches (when your app owns those settings):

```js
createQuickdraw({ container, themeToggle: false, gridControl: false })
```

Or toggle the whole toolbar at runtime: `ui.setHidden(true)`.
