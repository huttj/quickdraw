# Keyboard shortcuts

## Tools

| Key | Tool |
| --- | --- |
| `V` or `1` | Select |
| `H` | Hand (or hold `Space`) |
| `D`, `P`, or `B` | Draw |
| `I` | Highlight |
| `E` | Eraser |
| `K` | Laser pointer |
| `A` | Arrow |
| `L` | Line |
| `G` | Shape (current kind) |
| `R` | Rectangle |
| `O` | Ellipse |
| `T` | Text |
| `N` | Sticky note |

## Editing

| Key | Action |
| --- | --- |
| `⌘Z` / `⇧⌘Z` | Undo / redo |
| `⌘A` | Select all |
| `⌘C` / `⌘X` / `⌘V` | Copy / cut / paste |
| `⌘D` | Duplicate |
| `⌘G` / `⇧⌘G` | Group / ungroup |
| `⌫` | Delete selection |
| `⇧⌘⌫` | Clear the board (undoable) |
| `Enter` | Edit the selected shape's text, or crop the selected image |
| `Esc` | Done editing / leave crop mode / step out of a group / clear selection |
| Right-click or long press | Context menu |

## While editing text

| Key | Action |
| --- | --- |
| `⌘B` / `⌘I` / `⌘U` | Bold / italic / underline |
| `⇧⌘X` | Strikethrough |
| `⌘E` | Code |
| `⇧⌘H` | Highlight |
| `⌘K` | Link (the selection, or the word at the caret) |
| `⌘Enter` / `Esc` | Finish |

With text selected these apply to it; with nothing selected they apply to
what you type next. A small bar above the text offers the same buttons.

## Arranging

| Key | Action |
| --- | --- |
| `]` / `[` | Bring forward / send backward (one step) |
| `⇧]` / `⇧[` | Bring to front / send to back |
| `⌥A` / `⌥D` | Align left / right |
| `⌥W` / `⌥S` | Align top / bottom |
| `⌥H` / `⌥V` | Align centers horizontally / vertically |
| `⇧⌥H` / `⇧⌥V` | Distribute horizontally / vertically |
| Arrow keys | Nudge selection |
| `Shift` + arrows | Nudge farther |

## Dragging

| Modifier | While dragging |
| --- | --- |
| `⌥` | Move becomes a copy while held; let go and it's a move again. The drop keeps whichever is on |
| `Shift` | Move along one axis; resize proportionally; rotate in 15° steps |
| `⌥` or `Ctrl` | Resize about the centre |
| `⌥` | Tie an arrow end to the exact point on a shape (instead of its centre) |

Tools can also be dragged: pull the shape, arrow, line, text, or note tool
off the dock and let go on the board to drop a ready-made one there.

## Camera

| Key | Action |
| --- | --- |
| `⇧1` | Zoom to fit |
| `⇧0` | Reset zoom to 100% |
| `⌘+` / `⌘−` | Zoom in / out |
| Scroll | Pan (trackpad) / zoom (`⌘` + wheel) |
| Pinch | Zoom |

On Windows and Linux, `⌘` is `Ctrl`.
